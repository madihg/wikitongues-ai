# worker

Python side of the Igala speech programme: scoring (below) and the Modal GPU
worker (`speech.py`, `igala_speech/pipeline.py`). The scoring modules
`igala_speech/normalise.py` and `igala_speech/metrics.py` are ports of
`web/src/lib/speech/normalise.ts` and `metrics.ts`. Both sides read
`web/src/lib/speech/metrics.fixtures.json`, so a number computed in the app and
a number computed here are the same number.

## Run

```
cd worker && uv venv && uv pip install -e ".[dev]" && .venv/bin/pytest
.venv/bin/ruff check
```

Python 3.11 or 3.12. `.venv` is git-ignored.

## Change the scoring rules

Change the TypeScript and the Python together, add a fixture case, and run
`pnpm exec vitest run src/lib/speech/metrics.test.ts` (from `web/`) and
`pytest` (from `worker/`). The two must give the same numbers.

## The Modal worker

`speech.py` is one Modal app, `wikitongues-speech`, with five GPU functions
(transcribe, train_asr, evaluate, train_tts, synthesize) behind one ASGI app.
It holds no database credentials: it downloads clips from signed URLs in the
job's manifest, and every job ends with a signed POST to
`APP_BASE_URL/api/speech/jobs/callback`. The app writes the rows.

Endpoints (header `x-shared-secret` = `SPEECH_WORKER_SECRET` on all but /health):

| Method and path | Body | Answer |
| --- | --- | --- |
| GET /health | none | `{ok}` |
| POST /transcribe | `{jobId, manifest, modelRef?}` | `{callId, jobId}` |
| POST /train-asr | `{jobId, manifest, devManifest?, baseModel?, config?{numSteps, lr}}` | `{callId, jobId}` |
| POST /evaluate | `{jobId, manifest, modelRef?, manifestVersion}` | `{callId, jobId}` |
| POST /train-tts | `{jobId, manifest, baseModel?, config?}` | `{callId, jobId}` |
| POST /synthesize | `{jobId, modelRef, sentences: [{id, text}]}` | `{callId, jobId}` |
| GET /status/{callId} | none | `{status: running\|done\|failed}` |

`manifest` lines are the app's `TrainingLine` (id, url, durationMs, language,
transcript, transcriptStripped, speakerPseudonym, dialect, tier). Modal does not
say "queued" for a spawned call, so /status reports running until the call
returns. The callback is the truth.

Callback body: `{jobId, kind, status: succeeded|failed, gpuSeconds, costUsd,
modelRef, metrics, transcripts, outputs, error}`. Headers `x-shared-secret`,
`x-timestamp` (Unix seconds) and `x-signature` = hex HMAC-SHA256 of
`timestamp + "." + raw body` under `SPEECH_WORKER_SECRET`. Three attempts,
waiting 1 s then 2 s, re-signed each time. Logs hold ids and numbers only.

## Deploy (Halim)

```
modal secret create wikitongues-speech \
  SPEECH_WORKER_SECRET=<long random> APP_BASE_URL=https://<the app> \
  SUPABASE_URL=<project url> SUPABASE_SERVICE_ROLE_KEY=<service role key>
modal deploy worker/speech.py
```

Copy the URL the deploy prints into Vercel as `SPEECH_WORKER_URL`, and set the
same `SPEECH_WORKER_SECRET` in Vercel. Then the smoke test is one `evaluate` on
a handful of clips. The real branches (omnilingual-asr, the CTC recipe, EveryVoice)
are written from the packages' documented interfaces and have not been run:
the recipe argv is `ASR_RECIPE` in `igala_speech/pipeline.py`, the image pins
are unset in `speech.py` (pin them from the first green run), and the EveryVoice
steps need a project config and a vocoder checkpoint the first run will show.

## Mock mode and local commands

`SPEECH_WORKER_MOCK=1` makes every function deterministic on
`tests/fixtures/mock.json` (invented words and English; three sine-burst WAVs,
regenerated by `tests/fixtures/make_fixtures.py`). Training functions sleep 1 s
(`SPEECH_MOCK_SLEEP=0` skips it). No network, no GPU, no Modal account.

```
cd worker && uv venv && uv pip install -e ".[dev]"
.venv/bin/pytest && .venv/bin/ruff check
SPEECH_WORKER_MOCK=1 .venv/bin/python -m igala_speech.selftest   # CER 0.0, then 0.2
modal run worker/speech.py::selftest                              # same, through Modal (no GPU)
```

The Parquet writer test needs pyarrow, which only the Modal image installs; it
skips locally (`uv pip install pyarrow` to run it).

## Cost estimates

Rates (`igala_speech/rates.py`, https://modal.com/pricing): A10G $0.000306/s,
A100-80GB $0.000694/s, H100 $0.001097/s. The callback's `costUsd` is GPU seconds
in the function times that rate, an estimate; Modal's invoice is the truth.
The durations below are assumptions, not measurements: replace them after the
first real run.

| Job | GPU | Assumption | Estimate | Hard cap (function timeout) |
| --- | --- | --- | --- | --- |
| First baseline transcribe, about 21 audio hours (GRN plus first clips) | A10G | 180 s start and model download, 50x real time, 20 min of downloads | about $0.45 to $0.90 | $1.10 (1 h) |
| Evaluate, 1 audio hour | A10G | same speed | about $0.08 | $1.10 (1 h) |
| First fine-tune, 5000 steps | A100-80GB | 1.5 s per step, 10 min setup | about $5.60 | $29.98 (12 h) |
| TTS training | A10G | 6 h | about $6.60 | $26.44 (24 h) |
| Synthesize, 20 sentences | A10G | 2 min | about $0.04 | $1.10 (1 h) |
